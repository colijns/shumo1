# 问题2（2）报告：联合园区共享储能优化

## 一、问题分析

三个园区联合运营并共用一套储能。需要确定：储能额定功率 $P^{\mathrm{ess}}$、储能额定容量 $E^{\mathrm{ess}}$、24小时充放电策略、24小时电网购电计划，使联合园区年综合成本最低。

**口径差异**：本问在 Q2(1) 联合 profile 基础上引入共享储能，是 Q2(1) 的容量优化延伸。与 Q1(3) 各园区独立配储不同，本问是“一个共享储能池”服务联合负荷。仍为典型日、固定电价；储能投资按10年寿命线性年化，与问题3风光5年回报期口径不同（陷阱点）。

**输入数据**：附件1、附件2（同 Q2(1)），联合 profile 沿用 `q2_main.build_joint_profile`。代码与结果位于 `Q2/`，实现复用 Q1 统一 MILP 容量优化分支（`Q2/docs/adr/0001`），充电计价口径采用 View A（`Q2/docs/adr/0002`）。

## 二、模型假设

1. 联合负荷与风光出力沿用 Q2(1)（先聚合后平衡，不计园区间损耗）--**题目明示＋工程惯例**。
2. 储能充放电效率 $\eta_c=\eta_d=0.95$--**题目明示**。
3. SOC 允许范围 $[10\%, 90\%]$--**题目明示**。
4. 初末 SOC $=0.5E^{\mathrm{ess}}$（日末回归日初）--**建模抉择**（题目未规定，赛题拆解§5难点4）。
5. 储能充电按 0.4/0.5 元/kWh 计价（View A，与消纳同价）--**建模抉择**（`Q2/docs/adr/0002`，赛题拆解§5难点1，全题最大自由度）。
6. 不允许从电网充电（结构性禁止：模型无 $P_t^{\mathrm{grid,ch}}$ 变量）--**建模抉择**（`Q2/docs/adr/0002`）。
7. “只用余电充电”由 View A 成本结构涌现，非显式约束（缺电时段充电双重成本必然被规避）--**建模抉择**（`Q2/docs/adr/0002`）。
8. 充放电互斥（二进制 $z_t$）--**工程惯例**（赛题拆解§5难点8）。
9. 储能投资功率 800 元/kW、容量 1800 元/kWh、寿命10年，线性年化、不贴现、无残值--**题目明示**（单价/寿命）＋**建模抉择**（折算口径，赛题拆解§5难点2）。
10. 工程粒度 5 kW / 10 kWh--**工程惯例**。
11. 典型日 ×365 估算全年--**建模抉择**（赛题拆解§5难点2）。
12. 不向电网售电、弃电不计成本、消纳计成本--**题目明示**。

## 三、模型建立

设园区集合 $i\in\{A,B,C\}$，时段 $t=0,1,\ldots,23$，$\Delta t=1\ \mathrm{h}$。联合 profile $L_t^J,\ G_t^{\mathrm{pv},J},\ G_t^{\mathrm{w},J}$ 沿用 Q2(1)。

### 3.1 决策变量

| 符号 | 含义 | 单位 |
|---|---|---|
| $P^{\mathrm{ess}}$ | 储能额定功率 | kW |
| $E^{\mathrm{ess}}$ | 储能额定容量 | kWh |
| $P_t^{\mathrm{pv,L}},\ P_t^{\mathrm{w,L}}$ | 光伏、风电直接供给联合负荷 | kW |
| $P_t^{\mathrm{pv,ch}},\ P_t^{\mathrm{w,ch}}$ | 光伏、风电给储能充电 | kW |
| $P_t^{\mathrm{ch}},\ P_t^{\mathrm{dis}}$ | 储能充、放电功率 | kW |
| $P_t^{\mathrm{grid}}$ | 电网购电功率 | kW |
| $P_t^{\mathrm{curt,pv}},\ P_t^{\mathrm{curt,w}}$ | 弃光、弃风功率 | kW |
| $E_t$ | 储能电量（$t=0..24$） | kWh |
| $z_t$ | 充放电互斥二进制变量 | - |

### 3.2 约束条件

(1) 光伏出力分配：

$$P_t^{\mathrm{pv,L}}+P_t^{\mathrm{pv,ch}}+P_t^{\mathrm{curt,pv}}=G_t^{\mathrm{pv},J}.$$

(2) 风电出力分配：

$$P_t^{\mathrm{w,L}}+P_t^{\mathrm{w,ch}}+P_t^{\mathrm{curt,w}}=G_t^{\mathrm{w},J}.$$

(3) 总充电功率（结构性禁电网充电）：

$$P_t^{\mathrm{ch}}=P_t^{\mathrm{pv,ch}}+P_t^{\mathrm{w,ch}}.$$

(4) 联合负荷平衡：

$$P_t^{\mathrm{pv,L}}+P_t^{\mathrm{w,L}}+P_t^{\mathrm{dis}}+P_t^{\mathrm{grid}}=L_t^J.$$

(5) 储能电量递推：

$$E_{t+1}=E_t+\eta_c P_t^{\mathrm{ch}}\Delta t-\frac{P_t^{\mathrm{dis}}\Delta t}{\eta_d}.$$

(6) SOC 区间：

$$0.1E^{\mathrm{ess}}\leq E_t\leq 0.9E^{\mathrm{ess}}.$$

(7) 初末 SOC：

$$E_0=0.5E^{\mathrm{ess}},\qquad E_{24}=E_0.$$

(8) 充放电功率上限：

$$0\leq P_t^{\mathrm{ch}}\leq P^{\mathrm{ess}},\qquad 0\leq P_t^{\mathrm{dis}}\leq P^{\mathrm{ess}}.$$

(9) 充放互斥（$M$ 为大常数）：

$$P_t^{\mathrm{ch}}\leq Mz_t,\qquad P_t^{\mathrm{dis}}\leq M(1-z_t).$$

### 3.3 目标函数

典型日运行成本：

$$C^{\mathrm{day}}=\sum_t\left[0.4(P_t^{\mathrm{pv,L}}+P_t^{\mathrm{pv,ch}})+0.5(P_t^{\mathrm{w,L}}+P_t^{\mathrm{w,ch}})+1.0\cdot P_t^{\mathrm{grid}}\right]\Delta t.$$

储能年均投资：

$$C^{\mathrm{inv,ann}}=\frac{800P^{\mathrm{ess}}+1800E^{\mathrm{ess}}}{10}.$$

年综合成本：

$$\min C^{\mathrm{ann}}=365\,C^{\mathrm{day}}+C^{\mathrm{inv,ann}}.$$

### 3.4 参数取值

| 参数 | 取值 | 参数 | 取值 |
|---|---|---|---|
| $c_{\mathrm{pv}}$ | 0.4 元/kWh | $\eta_c,\ \eta_d$ | 0.95 |
| $c_{\mathrm{w}}$ | 0.5 元/kWh | SOC 区间 | 10%~90% |
| $c_{\mathrm{g}}$ | 1.0 元/kWh | 初末 SOC | $0.5E^{\mathrm{ess}}$ |
| 功率单价 | 800 元/kW | 容量单价 | 1800 元/kWh |
| 寿命 | 10 年 | $\Delta t$ | 1 h |

### 3.5 求解方法

三步求解 ＋ 两维敏感性：

1. **连续 MILP**：$P^{\mathrm{ess}},\ E^{\mathrm{ess}}$ 为连续变量，求理论最优；
2. **工程整数 MILP**：$P^{\mathrm{ess}}=5n_P$、$E^{\mathrm{ess}}=10n_E$，$n_P,n_E$ 为非负整数；
3. **2D 网格枚举**：$P\in[0,200]$ step 5 kW、$E\in[0,600]$ step 10 kWh，共 $41\times61=2501$ 点，逐点求最优调度，得全局最优与最优正配置 $(P>0,E>0)$；
4. **敏感性分析**：充电价 $c\in\{0,0.1,\ldots,0.5\}$、投资价缩放 $s\in\{0.5,\ldots,1.5\}$（复用网格日运行成本，不重解）。

不使用遗传算法、粒子群等近似算法，MILP 可直接得到全局最优。

## 四、结果与分析

### 4.1 方案对比

| 方案 | 储能功率/kW | 储能容量/kWh | 日运行成本/元 | 年均投资/元 | 年综合成本/元 |
|---|---:|---:|---:|---:|---:|
| 联合无储能 | 0 | 0 | 15107.661 | 0 | 5514296.083 |
| 固定50kW/100kWh | 50 | 100 | 15068.017 | 22000.000 | 5521826.305 |
| 连续优化 | 0 | 0 | 15107.661 | 0 | 5514296.083 |
| 工程整数优化 | 0 | 0 | 15107.661 | 0 | 5514296.083 |
| 最优正配置(P>0,E>0) | 5 | 10 | 15103.429 | 2200.000 | 5514951.556 |

连续 MILP、工程整数 MILP、2501 点 2D 网格三路同证：最优配置为 $P^{\mathrm{ess}}=0$、$E^{\mathrm{ess}}=0$，年综合成本 5514296.083 元，与 Q2(1) 联合无储能完全一致。

### 4.2 机理分析：为什么 0/0 最优

**边际经济学**：储能价值取决于“每 kWh 容量年化转移电量收益”与“年化投资”的比较。容量部分年化投资为 $1800/10=180$ 元/kWh。联合园区剩余风光有限（Q2(1) 无储能时日弃风弃光 1237.175 kWh，风光消纳率已达 92.437%），首批储能可消纳的电量很小。

以最优正配置 5 kW/10 kWh 为例：

- 年均投资 $=(800\times5+1800\times10)/10=2200$ 元；
- 日运行成本仅从 15107.661 降至 15103.429，每天节省 4.232 元（对应每天多消纳约 8.4 kWh 风光电）；
- 年化收益 $4.232\times365\approx1544.68$ 元；
- 净亏约 $655.47$ 元（$=5514951.556-5514296.083$），年化收益不足以覆盖年化投资。

固定 50/100 更亏：年运行节省 $365\times(15107.661-15068.017)\approx14470$ 元，远低于 22000 元年化投资，净亏 7530.22 元。

**根本原因**：Q2(1) 联合运营已通过园区间互济消纳了 92.437% 的风光，剩余弃电分散在各时段、单时段可消纳量极小，储能可搬运的电量不足以摊薄投资。这是“联合运营已吃掉大部分互补收益”的必然结果，而非模型错误。

### 4.3 三路求解同证

|---|---:|---:|---:|
| 连续 MILP | 0.000 | 0.000 | 5514296.083 |
| 工程整数 MILP | 0 | 0 | 5514296.083 |

## 五、模型检验

### 5.1 能量守恒与约束校验

0/0 时储能约束 vacuous，故用固定 50/100 方案验证有储能时的约束满足：

- 每小时功率平衡误差 $<10^{-4}$（实测 max $=0$）；
- 每小时风光出力分配误差 $<10^{-4}$（实测 max $=2.27\times10^{-13}$）；
- 不允许电网充电（结构性）：充电功率 $=$ 光伏充电 $+$ 风电充电，偏差 $=0$；
- 只用余电充电（涌现）：充电仅出现在风光有富余的时段，缺电时段不充电；
- 不同时充放电：$z_t$ 互斥约束生效；
- SOC 始终在 10%~90%，日末 SOC $=$ 日初；
- 年综合成本 $=365\times$ 日运行 $+$ 年均投资（重构 5514296.083 vs 5514296.083）。

### 5.2 充电成本敏感性

将储能充电价统一为 $c$ 元/kWh 扫描（负荷绿电价不变）：

| 充电价 $c$ | 最优功率/kW | 最优容量/kWh | 年综合成本/元 |
|---:|---:|---:|---:|
| 0.00 | 200.0 | 582.5 | 5204032.000 |
| 0.10 | 200.0 | 582.5 | 5289652.500 |
| 0.20 | 200.0 | 478.5 | 5374503.100 |
| 0.30 | 200.0 | 437.8 | 5457572.700 |
| 0.35 | 200.0 | 286.4 | 5497912.300 |
| 0.40 | 0.0 | 0.0 | 5514296.083 |
| 0.50 | 0.0 | 0.0 | 5514296.083 |

$c\leq0.35$ 时最优容量为正（功率顶到搜索上界 200 kW，说明经济性极好、真最优 $P$ 可能更大，但不影响 0/0 结论），$c\geq0.40$ 时归零。盈亏平衡充电价 $c^\ast\in(0.35,0.40]$。题目光伏充电价 0.4 恰在边界、风电 0.5 更高，故 0/0 最优。这从成本结构上证明零容量是经济决策，而非“大部分已消纳”的近似或模型错误。

> ADR 0002 手算盈亏平衡 $\approx0.32$ 为下界近似（仅算弃电转移），扫描定位真值在 $(0.35,0.40]$，因含峰谷套利等额外收益使真值高于纯弃电转移估算。

### 5.3 投资价格敏感性

将储能投资单价乘以缩放因子 $s$（复用网格日运行成本，不重解）：

| 0.50 | 110 | 600 | 5495378.300 |
| 0.60 | 110 | 600 | 5507058.300 |
| 0.70 | 5 | 20 | 5514256.800 |

| 1.00 | 0 | 0 | 5514296.083 |

$s\geq0.8$ 时维持 0/0，$s=0.7$ 时储能刚开始变经济（5/20，年综合比 0/0 低 39.3 元）。盈亏平衡投资缩放 $s^\ast\in(0.7,0.8)$，对应容量单价需降至 $1800\times0.69\approx1240$ 元/kWh 以下。题目基准 $s=1$（1800 元/kWh）远高于该阈值，故 0/0 最优。

## 六、结论

在联合运营基础上配置共享储能，最优配置为零功率、零容量（$P^{\mathrm{ess}}=0$、$E^{\mathrm{ess}}=0$），年综合成本 5514296.083 元，与 Q2(1) 联合无储能完全一致。连续 MILP、工程整数 MILP、2501 点 2D 网格三路独立求解同证这一结论。根本原因是 Q2(1) 联合运营已通过园区间互济消纳 92.437% 的风光，剩余弃电分散且单时段可消纳量极小，首批储能每天仅多消纳约 8.4 kWh，年化收益 1544.68 元不足以覆盖 2200 元年化投资，净亏约 655.47 元。

**适用边界**：0/0 结论在以下假设下成立，任一松动则结论可能被推翻：

1. **充电计价口径**（假设5，ADR 0002）：若储能充电视为免费弃电拯救（View B，充电价 $c=0$），最优容量跳变为正（$P=200$、$E=582.5$，年综合降至 5204032.000 元）。盈亏平衡充电价 $c^\ast\in(0.35,0.40]$，题目光伏充电价 0.4 恰在边界。
2. **储能投资价格**（假设9）：若容量单价降至 1240 元/kWh 以下（$s<0.7$），储能变经济。盈亏平衡 $s^\ast\in(0.7,0.8)$，题目基准 1800 元/kWh 远高于阈值。
3. **联合消纳基础**（Q2(1) 假设）：若园区间互济受限（计入网损或输电容量瓶颈），联合风光消纳率下降、剩余弃电增多，储能可搬运电量增加，0/0 可能被推翻。

本问的 0/0 结果是 Q2(3) 联合 vs 独立收益对比的基准--联合运营的收益来自园区间互济（Q2(1) 已实现），而非共享储能。
