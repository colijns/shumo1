# 问题3（2）复算修改说明

这版模型已经补上了储能 \(E/P\ge1\text{ h}\) 和最大绿色端点的两阶段求解，整体思路没有问题。现在主要需要再处理一下容量上界对 Pareto 结果的影响。

## 需要修改的地方

### 1. 放宽容量上界后重新计算 Pareto

目前最大绿色方案中：

- A园区新增光伏达到 6000 kW 上界；
- B园区新增风电接近 6000 kW，储能容量达到 12000 kWh 上界。

虽然当前折中方案没有触碰上界，但理想点归一化使用了最大绿色端点，因此端点被截断后，折中点也可能受到影响。

建议逐步扩大风光和储能容量上界，重新计算：

1. 纯经济最优端点；
2. 最大风光负荷占比端点；
3. 两个端点之间的9档 Pareto 目标；
4. 理想点距离和最终折中方案。

上界可以逐次扩大，直到推荐折中方案稳定且不触碰上界，不需要直接把极大的容量作为最终结果。

### 2. 补充储能时长上限

当前只有

\[
E^{\mathrm{ess}}\ge P^{\mathrm{ess}},
\]

即 \(E/P\ge1\text{ h}\)。建议增加一个较宽松的工程上限，例如

\[
E^{\mathrm{ess}}\le6P^{\mathrm{ess}},
\]

使储能持续时长满足

\[
1\text{ h}\le E/P\le6\text{ h}.
\]

这样可以避免最大绿色方案出现功率较小、容量过大的储能配置。

### 3. 保留最大绿色端点的两阶段求解

先求

\[
R_{\max}=\max R_{\mathrm{load}},
\]

再固定

\[
R_{\mathrm{load}}\ge R_{\max}-\varepsilon
\]

并最小化年总成本。不要直接采用第一次最大化绿色指标时返回的设备容量。

### 4. 修改两处报告文字

- C园区推荐储能功率为 435 kW，报告中“7月充电功率达到625 kW”应按新调度结果修改；
- “弃电不计成本”为本文采用的成本核算假设，不写成题目明确规定。

## 复算后需要提供

- A、B、C的新 Pareto 结果；
- 经济端点、最大绿色端点和折中点配置；
- 理想点距离表；
- 每个方案的容量上界触碰情况；
- 储能 \(E/P\)、风光负荷占比、消纳率、弃电量和年总成本；
- 新旧折中方案的简单对比。

最终采用重新计算后的折中方案。最大绿色端点中的超大容量仅用于展示高绿色目标的代价，不直接作为工程推荐配置。
