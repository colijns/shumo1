# 问题2（3）报告：联合运营相对独立运营的经济收益

## 一、问题分析

本问比较三个园区联合运营与各自独立运营的经济收益。需要说明联合运营带来多少年收益、收益从何而来。

**独立运营口径**：三个园区各自独立运营，每个园区单独配置储能、单独做功率平衡，再将三个园区结果相加。独立运营的储能配置取问题1的工程最优（A=0/0、B=35/120、C=60/70，合计 95/190）。

**联合运营口径**：三个园区作为整体联合运营，配置一座共享储能（问题2（2）推荐的 175 kW/890 kWh），先把每小时的负荷与风光出力逐时相加，再在总量层面统一做功率平衡。

**比较原则**：联合运营的绿色要求与独立运营并不天然对等（独立运营无消纳约束、联合运营采用 97% 消纳目标的 Pareto 折中方案），因此本文给出三层结果，逐层厘清"在何种比较基础上"联合运营更优：

1. **最终方案比较**：问题1独立工程最优与问题2（2）推荐的联合 97% 方案比较；
2. **纯经济比较**：独立与联合均采用各自的纯经济最优，反映不附加绿色要求时的直接经济收益；
3. **相同 97% 绿色标准补充比较**：A、B、C 独立运营时也分别满足 97% 消纳率，再与联合 97% 方案比较。

三层结果均使用不含弃电惩罚的年实际成本。联合运营年收益定义为

$$B=C_{\mathrm{ind}}^{\mathrm{ann}}-C_{\mathrm{joint}}^{\mathrm{ann}},$$

收益率为

$$r=\frac{B}{C_{\mathrm{ind}}^{\mathrm{ann}}}\times 100\%.$$

## 二、最终方案比较

独立运营采用问题1得到的工程最优方案：

| 园区 | 储能功率/kW | 储能容量/kWh |
|---|---:|---:|
| A | 0 | 0 |
| B | 35 | 120 |
| C | 60 | 70 |
| 独立合计 | 95 | 190 |

联合运营采用问题2（2）推荐方案：$P_J^{\mathrm{ess}}=175\ \mathrm{kW}$，$E_J^{\mathrm{ess}}=890\ \mathrm{kWh}$。两种最终方案对比如下：

| 指标 | 独立工程最优 | 联合97%方案 | 联合后的变化 |
|---|---:|---:|---:|
| 储能总功率/kW | 95 | 175 | +80 |
| 储能总容量/kWh | 190 | 890 | +700 |
| 日电网购电量/kWh | 9,719.693 | 7,589.870 | -2,129.823 |
| 日弃电量/kWh | 2,659.687 | 487.701 | -2,171.986 |
| 日运行成本/元 | 15,985.836 | 14,797.536 | -1,188.300 |
| 年运行成本/元 | 5,834,830.02 | 5,401,100.76 | -433,729.25 |
| 储能年化投资/元 | 41,800.00 | 174,200.00 | +132,400.00 |
| 年实际成本/元 | 5,876,630.02 | 5,575,300.76 | **-301,329.25** |
| 单位负荷电量年实际成本/元·kWh$^{-1}$ | 0.6884 | 0.6531 | -0.0353 |
| 风光消纳率 | 83.74% | 97.02% | +13.28 个百分点 |

$$B_{\mathrm{final}}=5{,}876{,}630.02-5{,}575{,}300.76=301{,}329.25\ \mathrm{元/年},$$

$$r_{\mathrm{final}}\approx 5.13\%.$$

虽然联合 97% 方案配置了更大的共享储能，使年化投资增加 13.24 万元，但园区互济与储能调度使年运行成本下降 43.37 万元，最终仍获得约 30.13 万元/年的净收益。同时，联合方案的风光消纳率为 97.02%，明显高于独立工程最优方案的 83.74%--联合最终方案在承担更高绿色要求的同时，年实际成本仍低于独立运营。

## 三、纯经济比较

在不设置消纳率约束时：独立工程最优配置合计为 95 kW/190 kWh（同上）；联合纯经济最优配置为 0 kW/0 kWh（问题2（2）已证）。

| 指标 | 独立纯经济最优 | 联合纯经济最优 | 联合后的变化 |
|---|---:|---:|---:|
| 储能总功率/kW | 95 | 0 | -95 |
| 储能总容量/kWh | 190 | 0 | -190 |
| 日电网购电量/kWh | 9,719.693 | 8,266.270 | -1,453.423 |
| 日弃电量/kWh | 2,659.687 | 1,237.175 | -1,422.512 |
| 年运行成本/元 | 5,834,830.02 | 5,514,296.08 | -320,533.94 |
| 储能年化投资/元 | 41,800.00 | 0 | -41,800.00 |
| 年实际成本/元 | 5,876,630.02 | 5,514,296.08 | **-362,333.94** |
| 风光消纳率 | 83.74% | 92.44% | +8.70 个百分点 |

$$B_{\mathrm{economic}}=362{,}333.94\ \mathrm{元/年},\qquad r_{\mathrm{economic}}\approx 6.17\%.$$

纯经济条件下，联合运营即便不配置储能（0/0），仅靠园区间互济就能降低年运行成本 32.05 万元，并省去独立侧重复的储能投资 4.18 万元，合计年收益 36.23 万元。该结果反映不附加绿色目标时，园区间互济和减少重复储能投资带来的直接财务收益。

## 四、相同 97% 绿色标准的补充比较

为检查联合运营在相同绿色要求下的优势，令 A、B、C 独立运营时分别满足 $R_{\mathrm{re},i}\geq 97\%$，得独立工程配置：

| 园区 | 储能功率/kW | 储能容量/kWh | 实际消纳率 |
|---|---:|---:|---:|
| A | 160 | 990 | 97.046% |
| B | 165 | 750 | 97.000% |
| C | 190 | 1,050 | 97.017% |
| 合计 | 515 | 2,790 | - |

与联合 97% 方案比较：

| 指标 | 独立各园区均≥97% | 联合整体≥97% | 联合后的变化 |
|---|---:|---:|---:|
| 储能总功率/kW | 515 | 175 | -340 |
| 储能总容量/kWh | 2,790 | 890 | -1,900 |
| 日电网购电量/kWh | 7,772.407 | 7,589.870 | -182.537 |
| 日弃电量/kWh | 487.831 | 487.701 | -0.130 |
| 日运行成本/元 | 14,991.760 | 14,797.536 | -194.223 |
| 年运行成本/元 | 5,471,992.33 | 5,401,100.76 | -70,891.57 |

在园区级相同 97% 标准下，两侧风光消纳率几乎相同（97.02%），但联合运营的共享储能容量仅为独立合计的 890/2790 ≈ 31.9%，储能年化投资减少 36.92 万元，是收益的主要来源。这一补充情景采用"每个独立园区都达到 97%"的较严格要求，用于说明共享储能能够显著减少重复建设，不替代第二节的最终方案比较。

## 五、收益来源分析

### 1. 园区间直接电力互济

某园区风光富余时，可直接供给存在负荷缺口的其他园区，减少外部购电和弃电。纯经济比较中，联合 0/0 较独立 95/190 日购电减少 1,453.423 kWh、日弃电减少 1,422.512 kWh，这是不配置储能也能获得 36.23 万元年收益的主要原因。

### 2. 风光与负荷时序互补

光伏主要集中在白天，风电出力分布相对分散；三个园区负荷峰谷出现时间也不完全一致。聚合后净负荷曲线更加平滑，降低了外部购电和弃电。

### 3. 共享储能降低重复建设

独立运营时，每个园区需分别应对自身的供需错配；联合运营先进行园区间互济，再由一套共享储能处理剩余错配。在相同 97% 园区级绿色标准下，储能容量由独立合计 2,790 kWh 降至联合 890 kWh，降幅近 68%。

### 4. 规模效应与统一调度

联合优化可在更大的时空范围内安排风光直供、储能充放电和电网购电，使储能利用率提高，减少低利用率容量。

### 5. 收益边界

当前模型未考虑园区间线路投资、传输损耗、容量限制和内部交易费用，因此得到的是理想联合条件下的收益。若加入这些因素，实际收益会有所下降。

## 六、结论

采用问题1独立工程最优与问题2（2）联合 97% 推荐方案比较，联合运营的年实际成本降低约 **30.13 万元**，收益率约 **5.13%**。在纯经济条件下，联合运营年收益约 **36.23 万元**，收益率约 **6.17%**。在各独立园区均满足 97% 消纳率的补充情景下，联合运营可减少共享储能重复投资，年收益约 **44.01 万元**，收益率约 **7.32%**。

三层比较中，联合最终方案在承担更高绿色要求（97.02% vs 83.74%）的同时年实际成本仍低于独立运营，且在相同 97% 标准下以不到三分之一独立合计的储能容量达到同等消纳水平。综合来看，联合运营的收益主要来自园区间直接互济、风光荷时序互补和共享储能规模效应。
