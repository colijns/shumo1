# 问题1 模型假设

> 适用范围:问题1(各园区独立运营)的无储能仿真、固定 50kW/100kWh 储能运行优化、储能容量优化配置三个子场景。
> 对应代码:`Q1/data_loader.py`、`Q1/milp_model.py`、`Q1/q1_main.py`、`Q1/grid_search.py`。

---

## 一、时间尺度与代表周期假设

1. **典型日代表全年**:以附件1、附件2给出的 1 个典型日 24h 曲线代表全年运行工况,且典型日重复 365 天。年运行成本 = 365 × 典型日运行成本。
   - 实现位置:`milp_model.py` 目标函数 `365 * daily_cost + annual_inv`。

2. **时段离散化**:取 Δt = 1h,全天 24 个时段,每个时段内各类功率恒定不变。
   - 实现位置:`data_loader.py` `DT = 1.0`。

3. **投资直线折旧、不计贴现与残值**:储能寿命 10 年,投资按直线法均摊到每年(年均投资 = 总投资 / 10),不考虑资金时间价值、贴现率与残值。
   - 实现位置:`milp_model.py` `(C_P_ESS * P + C_E_ESS * E) / Y`,`Y = 10`。

## 二、储能运行假设

4. **充放电效率恒定**:充电效率 η_c = 0.95、放电效率 η_d = 0.95,全天恒定,不随功率/SOC 变化。
   - 实现位置:`data_loader.py` `ETA_C = 0.95`、`ETA_D = 0.95`。

5. **SOC 工作区间**:SOC 限定在 [10%, 90%],避免过充过放以保护电池。
   - 实现位置:`data_loader.py` `S_MIN = 0.10`、`S_MAX = 0.90`。

6. **周期性边界**:初始 SOC = 50%,且日末 SOC 必须回归到初始值(E[24] = E[0]),保证储能不跨日净积累或净消耗能量。
   - 实现位置:`milp_model.py` `E[0] == S_0 * E_ess`、`E[24] == E[0]`。

7. **充放电互斥**:同一时段不允许同时充放电,用大 M 法 + 0-1 变量 z[t] 线性化(P_ch ≤ M·z,P_dis ≤ M·(1−z))。
   - 实现位置:`milp_model.py` 互斥约束 `mutex_ch`、`mutex_dis`。

8. **仅由剩余风光充电**:储能只能用光伏/风电富余部分充电,禁止从电网购电充储能(P_ch = P_ch_pv + P_ch_w,无电网充电项)。
   - 实现位置:`milp_model.py` `P_ch[t] == P_ch_pv[t] + P_ch_w[t]`。

9. **功率受限**:各时段充、放电功率均不超过储能额定功率。
   - 实现位置:`milp_model.py` `P_ch[t] <= P_ess`、`P_dis[t] <= P_ess`。

## 三、电力平衡与购售电假设

10. **园区独立运营**:三个园区各自独立完成功率平衡,园区之间无功率交换、无共享储能。
    - 实现位置:`q1_main.py` 逐园区调用 `solve_park_optimization`。

11. **可再生能源优先消纳**:通过成本排序体现优先级--光伏 0.4 元/kWh、风电 0.5 元/kWh 均低于电网 1.0 元/kWh,模型在成本最小化下自然优先消纳绿电。
    - 实现位置:`data_loader.py` `C_PV = 0.4`、`C_W = 0.5`、`C_G = 1.0`;目标函数。

12. **禁止余电上网**:风光富余电力不得向主网售电(售电价 = 0),**弃风弃光**是唯一出口,弃电量作为非负松弛变量处理。
    - 实现位置:`milp_model.py` `P_curt_pv`、`P_curt_w` ≥ 0,无售电变量。

13. **风光出力全额可分配**:每个时段风光出力等于"直供电负荷 + 充电 + 弃电"三路之和。
    - 实现位置:`milp_model.py` `pv_balance`、`w_balance` 约束。

## 四、成本口径假设

14. **弃电零成本零收益**:目标函数只对**实际消纳**的风光电计购电成本,弃电既不计成本也无收益。
    - 实现位置:`milp_model.py` 目标函数不含 P_curt 项。

15. **年综合成本口径**:年综合成本 = 365 × 日运行成本 + 年均投资,使"日级运行节省"与"年级投资支出"在同一时间尺度可比。
    - 实现位置:`milp_model.py` `annual_cost = 365 * daily_cost + inv_annual`。

16. **单位供电成本分母**:单位电量平均供电成本 = 总成本 / 负荷电量(以负荷电量为分母),三场景同口径以保证 (1)(2)(3) 小问可比。
    - 实现位置:`milp_model.py` `unit_daily_cost`、`unit_annual_cost`。

17. **三场景同口径**:无储能、固定 50kW/100kWh、优化容量三种方案均通过同一个 MILP 模型求解,仅储能容量取值方式不同,确保对比一致性。
    - 实现位置:`run_no_storage / run_fixed_storage / run_optimized_storage` 均调用 `solve_park_optimization`。

## 五、数据与装机假设

18. **归一化出力换算**:附件2为标幺化数据,实际出力 = 标幺值 × 装机容量。
    - 实现位置:`data_loader.py` `G_pv['A'] = data['A_pv'] * PARKS['A']['pv']` 等。

19. **装机容量给定不变**:A 光伏 750kW;B 风电 1000kW;C 光伏 600kW + 风电 500kW(问题1不涉及装机规划)。
    - 实现位置:`data_loader.py` `PARKS`。

20. **无网损**:园区内部功率传输无损耗,功率平衡为严格等式(各类损耗仅体现在储能充放电效率中)。
    - 实现位置:`milp_model.py` `load_balance` 等式无损耗项。

## 六、工程离散化假设(仅(3)优化容量场景)

21. **工程粒度取整**:储能功率按 5kW 粒度、容量按 10kWh 粒度取整数倍,以反映设备工程可实现性。
    - 实现位置:`q1_main.py` `P_STEP = 5`、`E_STEP = 10`。

22. **搜索上界**:容量优化搜索范围限定为功率 ≤ 200kW、容量 ≤ 600kWh。
    - 实现位置:`q1_main.py` `P_MAX = 200`、`E_MAX = 600`。

23. **两阶段求解 + 复核**:先求连续理论最优,再在工程整数倍上求 MILP 最优,并用局部网格(同粒度)复核,确认工程整数解即全局最优。
    - 实现位置:`q1_main.py` 依次调用 `run_optimized_storage` → `run_engineering_storage` → `grid_search_capacity`。
