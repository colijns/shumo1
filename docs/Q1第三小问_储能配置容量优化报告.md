# 问题三：储能额定功率与容量协同优化

## 1. 问题分析

问题一前两小问中，储能额定功率 $P_s$ 与容量 $E_s$ 为给定参数。第三小问将其提升为决策变量，在满足微电网运行约束的前提下，以**年综合成本最小**为目标，确定各园区最优储能配置。年综合成本由典型日运行成本（按 365 天折算）与储能投资年折旧两部分构成：

$$\min \; C_{\text{annual}} = 365 \cdot C_{\text{daily}} + \frac{800\,P_s + 1800\,E_s}{10}$$

其中 $800$、$1800$ 分别为储能功率单价（元/kW）与容量单价（元/kWh），$10$ 为储能寿命（年），按直线法折旧。

## 2. 模型建立

对每个园区独立建模，时间 horizon 为典型日 24 时段，$\Delta t = 1\,\text{h}$。记光伏出力 $G_{pv,t}$、风电出力 $G_{w,t}$、负荷 $L_t$。

### 2.1 决策变量

**容量层**：$P_s$、$E_s$（储能额定功率、容量）。

**运行层**（$t=0,1,\dots,23$）：
- $P_{L,pv,t}$、$P_{L,w,t}$：光伏、风电直供负荷功率；
- $P_{ch,pv,t}$、$P_{ch,w,t}$：以光伏、风电对储能充电的功率；
- $P_{curt,pv,t}$、$P_{curt,w,t}$：弃光、弃风功率；
- $P_{ch,t}$、$P_{dis,t}$：储能总充、放电功率；
- $E_t$（$t=0,\dots,24$）：储能电量；
- $z_t \in \{0,1\}$：充放电状态二元变量；
- $P_{g,t}$：电网购电功率。

### 2.2 目标函数

典型日运行成本对实际消纳的风光电与网购电计费，储能充电能量按对应绿电价计价（与消纳同价）：

$$C_{\text{daily}} = \sum_{t=0}^{23}\Big( c_{pv}(P_{L,pv,t}+P_{ch,pv,t}) + c_w(P_{L,w,t}+P_{ch,w,t}) + c_g P_{g,t} \Big)\Delta t$$

其中 $c_{pv}=0.4$、$c_w=0.5$、$c_g=1.0$（元/kWh）。年综合成本即 $365\,C_{\text{daily}} + (800\,P_s+1800\,E_s)/10$。

### 2.3 约束条件

**(1) 风光出力平衡**

$$P_{L,pv,t}+P_{ch,pv,t}+P_{curt,pv,t}=G_{pv,t},\quad P_{L,w,t}+P_{ch,w,t}+P_{curt,w,t}=G_{w,t}$$

**(2) 负荷功率平衡**

$$P_{L,pv,t}+P_{L,w,t}+P_{dis,t}+P_{g,t}=L_t$$

**(3) 储能充电功率合成**

$$P_{ch,t}=P_{ch,pv,t}+P_{ch,w,t}$$

**(4) 储能电量递推**

$$E_{t+1}=E_t+\eta_c P_{ch,t}\Delta t - \frac{P_{dis,t}\Delta t}{\eta_d},\quad \eta_c=\eta_d=0.95$$

**(5) SOC 上下限**

$$0.10\,E_s \le E_t \le 0.90\,E_s$$

**(6) 初始与日末 SOC**

$$E_0 = 0.50\,E_s,\quad E_{24}=E_0$$

**(7) 充放电功率上限**

$$0\le P_{ch,t}\le P_s,\quad 0\le P_{dis,t}\le P_s$$

**(8) 充放电互斥**（引入二元变量与大常数 $M$）

$$P_{ch,t}\le M z_t,\quad P_{dis,t}\le M(1-z_t),\quad z_t\in\{0,1\}$$

**(9) 非负与方向约束**：各功率非负；$P_{g,t}\ge 0$（不允许余电上网）；$P_s\ge 0$、$E_s\ge 0$（不配储能可行）。

由于存在二元变量 $z_t$，模型为**混合整数线性规划（MILP）**。

## 3. 求解策略

采用"连续理论最优 -> 工程整数最优 -> 局部网格验证"三步法。

### 3.1 第一步：连续变量理论最优

视 $P_s$、$E_s$ 为连续变量，连同 24 个二元充放电状态变量 $z_t$ 一并求解上述 MILP，得到理论最优配置。该解给出年综合成本的下界，但因 $P_s$、$E_s$ 可取任意实数，工程上不可实现。

### 3.2 第二步：工程粒度整数最优

按工程可实现粒度将容量离散化：令

$$P_s = 5\,n_P,\quad E_s = 10\,n_E,\quad n_P\in\{0,1,\dots,40\},\; n_E\in\{0,1,\dots,60\}$$

即功率以 5 kW、容量以 10 kWh 为步长，搜索上界 200 kW / 600 kWh。$n_P$、$n_E$ 为整数变量，代入原模型重新求解 MILP。由于 $n_P=n_E=0$ 可行，"不配置储能"自动纳入备选集，与配置储能的方案在同一目标下公平比较。此步得到工程可实现的整数最优配置。

### 3.3 第三步：局部网格交叉验证

以第二步的工程整数最优解 $(P_s^*, E_s^*)$ 为中心，在功率 $\pm 20\,\text{kW}$、容量 $\pm 40\,\text{kWh}$ 窗口内，按相同的 5 kW / 10 kWh 粒度构造网格。对每个网格点 $(P_s, E_s)$，固定容量后求解最优运行子问题（仍为含互斥约束的 MILP），计算年综合成本，取网格最低点与第二步结果比对，以验证整数最优解未漏掉更优的工程配置。

## 4. 求解结果

| 园区 | 无储能年成本（元） | 连续理论最优 $P_s/E_s$ = 年成本（元） | 工程整数最优 $P_s/E_s$ = 年成本（元） | 网格验证 |
|:---:|---:|---:|---:|:---:|
| A | 2,220,979.38 | 0 / 0 = 2,220,979.38 | 0 / 0 = 2,220,979.38 | 一致 |
| B | 1,850,969.75 | 32.2 / 114.7 = 1,845,890.39 | 35 / 120 = 1,846,084.92 | 一致 |
| C | 1,811,608.51 | 58.8 / 69.8 = 1,809,459.73 | 60 / 70 = 1,809,565.72 | 一致 |

## 5. 结论

1. **园区 A 不配置储能即为最优**：连续理论最优解 $P_s=E_s=0$，说明对 A 园区而言配置储能不能进一步降低年综合成本，"不配储能"自动成为最优备选方案。
2. **工程整数最优较连续最优年成本略升**：B 园区由 1,845,890.39 元升至 1,846,084.92 元，C 园区由 1,809,459.73 元升至 1,809,565.72 元，差额源于容量离散化，幅度可控。
3. **离散化非简单取整**：以 B 园区为例，连续解为 32.2 kW / 114.7 kWh，简单取整倾向于 30/110 或 35/115，而整数规划搜出 35 kW / 120 kWh 这一全局更优的工程点，体现了直接求解整数 MILP 的必要性。
4. **交叉验证通过**：三园区局部网格最优解均与工程整数最优解一致，表明整数规划求解结果可靠、无漏解。

最终工程配置方案为：园区 A 不配储能；园区 B 配置 35 kW / 120 kWh 储能；园区 C 配置 60 kW / 70 kWh 储能。
