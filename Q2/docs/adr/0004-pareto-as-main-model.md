# ADR 0004：Pareto ε-约束法作为 Q2(2) 主模型，λ 法降级为补充

**状态**：采纳（取代 ADR 0002 / 0003 的"主结论"框架，2026-07-25）
**取代**：ADR 0002、ADR 0003 的主结论定位（两者的建模口径、代码、测试仍有效，见下）

## 背景

ADR 0002 确立 Q2(2) 共享储能的**纯经济最优为 0 kW / 0 kWh**（年实际成本 5,514,296.083 元），理由是弃电不计成本时首批储能的年化收益（1,544 元）小于年化投资（2,200 元），净亏 655 元。该结论在纯经济口径下严格成立，且经连续 MILP、工程整数 MILP、2,501 点网格三路同证。

ADR 0003 进一步引入弃电惩罚项 λ·Σ(P_curt_pv+P_curt_w)·Δt（λ∈{0, 0.3, 0.6} 元/kWh），展示"对弃电计价"如何把最优配置从 0/0 推向正配置（λ=0.3→335/1310、λ=0.6→450/1470），并定调 λ=0.3 为推荐、工程整数落地 335 kW/1310 kWh。

两份 ADR 存在两个未解决的方法论问题：

1. **0/0 作为"最终方案"不合工程直觉**。赛题要求"合理配置储能"以提升风光消纳，纯经济最优 0/0 使消纳率停留在 92.44%，与"配置储能"的题意存在落差；直接以 0/0 作答难以服人。
2. **λ 法的推荐方案依赖主观政策判断**。λ 的物理含义是"弃电的等效罚值"，其取值无客观依据--λ=0.3 与 λ=0.6 的选型靠边际分析主观裁定，不同 λ 给出截然不同的配置（335/1310 vs 450/1470），结论不稳健。

## 决策

将 **ε-约束法构造的 Pareto 前沿**作为 Q2(2) 主模型，λ 法降级为补充敏感性分析。

### 主模型：ε-约束 Pareto 前沿 + 等权理想点距离选型

- **目标**：min C_ann = 365·C_day + C_inv,ann（年实际成本，**不含弃电惩罚**）
- **ε-约束**：风光消纳率 R_re = 1 − E_curt/E_re ≥ R0，R0 ∈ {95%, 97%, 98%, 99%, 100%}
- **前沿**：每个 R0 求连续 MILP 理论最优与工程整数（5 kW/10 kWh 粒度）最优，得到年实际成本-消纳率 Pareto 前沿
- **选型**：候选集 = {纯经济基准 0/0} ∪ {各 R0 连续最优}；等权归一化理想点距离
  Ĉ = (C−C_min)/(C_max−C_min)，Ĝ = (R_max−R)/(R_max−R_min)，d = √(Ĉ²+Ĝ²)
  取 d 最小者为折中目标 R0\*，再取该 R0\* 的工程整数方案为推荐配置

### 推荐结果

- **R0\* = 97%**，工程整数配置 **175 kW / 890 kWh**
- 实际消纳率 97.019%，年实际成本 5,575,300.76 元
- 较 0/0 纯经济基准年实际成本增加 61,004.68 元（换取消纳率从 92.44% 提升至 97.02%）

### 为什么取代 0/0 与 λ 法作为主结论

| 维度 | 0/0（ADR 0002） | λ=0.3（ADR 0003） | Pareto 97%（本 ADR） |
|---|---|---|---|
| 消纳率 | 92.44% | 99.43% | 97.02% |
| 年实际成本 | 5,514,296.08 | 5,626,415.01（含 λ 罚） | 5,575,300.76 |
| 选型依据 | 纯经济（弃电免费） | 主观政策 λ | 客观折中（理想点距离） |
| 口径 | 不含弃电惩罚 | 含弃电惩罚 | 不含弃电惩罚 |
| 题意契合 | 储能为 0，落差 | 过度绿色 | 折中，配置为正 |

Pareto 法的选型不依赖任何主观参数：R0 是工程上可解释的消纳率目标，理想点距离是客观的折中准则。0/0 作为前沿的纯经济端点保留，λ 法作为"弃电等效价值"的敏感性补充保留。

## 实现

### 共享 MILP 扩展（向后兼容）

`Q1/milp_model.py::solve_park_optimization` 新增可选参数 `min_accom_rate=None`：

```python
# (12) 最低风光消纳率约束（ε-约束法，构造 Pareto 前沿用）
if min_accom_rate is not None:
    _re_gen_daily = float(np.sum(G_pv) + np.sum(G_w)) * DT
    _curt_daily = pulp.lpSum([(P_curt_pv[t] + P_curt_w[t]) * DT for t in t_range])
    prob += _curt_daily <= (1.0 - float(min_accom_rate)) * _re_gen_daily
```

`min_accom_rate=None`（默认）时不施加约束，Q1/Q2.1/Q2.2 无惩罚版逐位不变（26 + 15 测试回归守护）。`Q1/grid_search.py::grid_search_capacity` 同步透传该参数。

## 与 ADR 0002 / 0003 的关系

- **ADR 0002**：充电计价口径（0.4/0.5）、0/0 为纯经济最优的结论**仍然有效**，作为 Pareto 前沿的纯经济端点（基准候选）被纳入选型。被取代的仅是"0/0 为 Q2(2) 最终方案"的主结论定位。
- **ADR 0003**：λ 法的实现、λ=0 锚定 0/0、λ>0 推动配置翻正的机理分析**仍然有效**，作为补充敏感性分析独立成文（`docs/问题2（2）lambda敏感性.md`）。被取代的仅是"λ=0.3 为推荐方案"的主结论定位。
- **本文（0004）**：确立 Pareto 97%→175/890 为 Q2(2) 主结论。λ 法不再决定最终方案，仅用于说明弃电等效价值变化对配置的影响。
