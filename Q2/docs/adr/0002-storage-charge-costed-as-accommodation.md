# 储能充电能量按消纳计价（0.4/0.5），不视为免费弃电拯救

> **状态：主结论已被 ADR 0004 取代（2026-07-25）；建模口径仍有效**
> 本 ADR 确立的充电计价口径（0.4/0.5）与"0/0 为纯经济最优"结论**仍然有效**，
> 0/0 在 ADR 0004 中作为 Pareto 前沿的纯经济端点（基准候选）被纳入选型。
> 被取代的仅是"0/0 为 Q2(2) 最终方案"的主结论定位--ADR 0004 改以 ε-约束
> Pareto 前沿的 97% 折中点（175 kW/890 kWh）为主结论。详见
> `0004-pareto-as-main-model.md`。

## 背景

Q2(2) 共享储能是否配置、配置多大，完全取决于"原本会被弃掉的风光，送去储能充电时如何计成本"。赛题拆解 `docs/赛题结构化拆解.md` §5 难点 1 将此列为"全题最大的建模自由度与风险点"。

边际经济学核算（η_c=η_d=0.95、SOC∈[10%,90%]、日一充一放）：

- 可用容量 0.8 E_ess，往返效率 0.95²=0.9025；
- 每 kWh 容量年收益 = 0.76×365×1.0 − (0.8/0.95)×365×c = 277.4 − 307.3c；
- 年化投资 = 1800/10 = 180 元/kWh；
- 盈亏平衡充电价 c\* ≈ 0.32 元/kWh。

光伏 0.4、风电 0.5 均高于 c\*，故每 kWh 容量年净亏约 26~56 元，最优配置为 0/0。若充电成本记为 0（视弃电拯救为免费），则每 kWh 容量年赚约 97 元，最优容量显著为正，0/0 被推翻。

## 决策

采用 **View A**：储能充电消耗的风光按 0.4 元/kWh（光伏）、0.5 元/kWh（风电）计成本，与 Q1/Q2(1) "弃电不计成本、消纳计成本"口径完全一致。

理由：储能充电是"抽取风光并使用"，属于**消纳**，不是弃电拯救。Q2(1) 假设 7 的"弃电不计成本"只针对真正被丢弃的能量；进入储能的能量未被丢弃，应按消纳计价。目标函数因此为

$$
C^{\mathrm{day}}=\sum_t\left[0.4(P_t^{\mathrm{pv,L}}+P_t^{\mathrm{pv,ch}})+0.5(P_t^{\mathrm{w,L}}+P_t^{\mathrm{w,ch}})+P_t^{\mathrm{grid}}\right]\Delta t.
$$

## Considered Options

- **View A：充电计 0.4/0.5 -- 采用**。口径与 Q1/Q2(1) 一致，0/0 成立，Q2(3) 互济叙事自洽。代价：储能永远不经济，2(2) 退化为"证明不配储"。
- **View B：充电计 0（拯救弃电免费）**。储能有利可图，最优容量为正。但与"消纳计成本"口径冲突，需先改 Q2(1) 假设 7，并重写 Q2(3) 收益分解。
- **View C：加弃电惩罚项**（如 0.3 元/kWh 弃电）。不改充电成本，强制提高消纳。但改变全题目标函数，须同步回 Q1/Q2(1) 重算。

## Consequences

- Q2(2) 最优配置为 $P^{\mathrm{ess}}=0,\ E^{\mathrm{ess}}=0$，运行策略与购电计划退化为 Q2(1) 联合无储能结果。
- 必须在论文中给出**边际经济学论证**（盈亏平衡价 0.32、年净亏 26~56 元/kWh）和**容量-年综合成本曲线**，证明 0/0 是全局最优而非模型错误。
- 必须做**充电成本敏感性分析**（c 从 0 扫到 0.5），展示最优容量在 c<0.32 时跳变为正、在 c≥0.32 时维持 0，证明结论对口径稳健。
- Q2(3) 收益分解（运行成本下降 32.05 万 + 储能投资节省 4.18 万 = 36.23 万）不变。
- `问题2（2）.md` §6 现有理由"联合运营已消纳大部分富余风光"不准确（Q2(1) 仍剩 1237 kWh/天弃电），应改为"边际容量收益不足以覆盖投资"。
