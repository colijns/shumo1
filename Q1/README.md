# 问题1运行说明

## 运行

在项目根目录执行：

```bash
pip install -r requirements.txt
python Q1/q1_main.py
```

结果保存在 `Q1/output/`。

## 当前模型口径

- 典型日重复365天；
- 储能寿命10年，投资按直线法折算；
- 充、放电效率均为0.95；
- SOC范围10%～90%，初始和日末SOC均为50%；
- 储能只使用剩余风光充电，不允许电网充电；
- 不允许余电上网；
- 基准模型只对实际消纳的风光电计成本；
- 工程功率粒度5 kW，容量粒度10 kWh。

## 最终工程方案

| 园区 | 储能功率 | 储能容量 | 年综合成本 |
|---|---:|---:|---:|
| A | 0 kW | 0 kWh | 2,220,979.38元 |
| B | 35 kW | 120 kWh | 1,846,084.92元 |
| C | 60 kW | 70 kWh | 1,809,565.72元 |

程序先求连续理论最优，再把储能功率、容量直接设置为工程步长的整数倍进行MILP优化。局部网格使用相同粒度复核，三个园区的结果均与工程整数最优一致。

`问题1_逐时调度表.xlsx` 包含：

- `逐时调度`：24小时功率调度；
- `SOC轨迹`：包含日末状态的25个SOC点。
